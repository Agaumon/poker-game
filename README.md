# Python Poker Game

A Python card-game project exploring poker game logic through two variations: Texas Hold'em and Three Card Poker. The repository organizes the game implementations into separate directories and provides an opportunity to practice programming fundamentals through card-game rules and interactions.

## Project Structure

- `texasHoldem/` — Implementation files for the Texas Hold'em variation.
- `threeCard/` — Implementation files for the Three Card Poker variation.

## Technologies

- Python 3
- Conditional logic
- Functions
- Data structures
- Loops and program flow

## Getting Started

### Prerequisites

- Python 3 installed on your system.

### Installation

Clone the repository:

```bash
git clone https://github.com/Agaumon/poker-game.git
cd poker-game
```

### Run the game

Open either the `texasHoldem/` or `threeCard/` directory and locate its main Python script. Run the appropriate file using Python:

```bash
python path/to/game_script.py
```

Replace the example path with the actual script path in the selected directory. Use `python3` instead of `python` if required by your environment.
